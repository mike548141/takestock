# 2026-11-14 — Roadmap: one file per item

Dispatched by an estate health sweep (orchestrator session `58027096`): split
the one-file roadmap into a board, one file per item, as atelier's
`RECORD.md` expects of every record store kept as a list.

## What was done

- **Roadmap split.** Each roadmap item is now its own file under
  `docs/roadmap/<NNN>-<section>/<NNN>-<slug>.md`, its state line first, in
  four numbered sections (Now, Next, Later, Queued reviews), each with a
  `README.md` holding its heading. `docs/roadmap/README.md` says what the
  board is for and gives the state lines. `docs/ROADMAP.md` is now the index
  generated by atelier's `tools/board.py --rebuild`.
- Every item's text was carried over word for word; the only addition is a
  `[ ]` state line on the five items that had none.
- `CLAUDE.md` § *Records* names the board and its index, and the read order
  starts at the index. The changelog says where the roadmap now lives.

## What was checked

- A line-by-line comparison of the old file with the new ones: every
